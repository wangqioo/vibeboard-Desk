# ATOM 产品体验整合 V1

目标：保持独立设备、全屏应用和现有主题，把应用集合连成可靠的日常体验。本轮不增加覆盖所有应用的常驻宠物，不声称已有语音聊天或电脑Agent连接。

1. 应用生命周期：统一启动反馈、8秒延迟提示、加载失败重试和返回。使用真实窗口加载与应用ready消息，不给虚假百分比。退出拆除iframe、发送suspend、停止系统表情动画；旧iframe消息不能影响新应用。
2. 系统表情：复用RoboEyes真实动画引擎。录音=倾听，转写与生成=思考，检查完成与安装=开心，错误=困惑。只出现在工作坊对应页面；设置提供动画开关，尊重减少动态效果偏好。
3. 工作坊连续性：草稿保存、后台生成、桌面任务标记、网络暂断后继续查询、刷新后恢复任务。停止录音后再离开；未配置转写时提供明确提示和文字输入路径。
4. 应用规范：统一AtomApp v1接口，异步初始化可deferReady/ready；每个已安装应用只有自己的64KiB JSON保存空间；预览空间为临时，不冒充永久保存。模板、模型提示与开发指南一起更新。主题控制颜色和图标；默认单屏，仅必要局部列表允许滚动。
5. 验证与部署：接口单元测试、真机启动/失败/恢复/空间隔离/键盘返回/主题/后台任务测试；真实模型生成一个使用保存接口的实用小工具，安装、保存、重开验证；保留原应用顺序，新增应用追加。

验收证据记录在artifacts。源码和许可保留；现有模型凭据不输出、不写入应用包。动画是状态反馈，不用随机表情冒充设备状态。
