# ATOM 第一版开发计划

目标：在现有透明板 Debian 系统上交付独立的主界面、基础应用、应用管理服务和可恢复的启动方式。保持板厂内核及驱动，先验证产品体验，再精简桌面。

## 第一版范围

- 本地独立运行时钟、计时器和系统状态，计时器状态持久化。
- 统一应用入口、返回主页、音量调节及系统状态。
- 提供本地受控 Web 应用安装、更新及卸载接口；不执行应用附带的系统代码。
- 本地 HTTP 服务仅监听回环地址，远程开发使用 SSH 隧道。
- 不迁移内核、不批量升级驱动、不移除已有桌面，不把本地大模型引入本次交付。

## 开发分工

- 主 Agent：备份、计划、启动脚本、部署、集成、真机验证和结果记录。
- 界面 Agent：静态主界面与示例应用。
- 服务 Agent：Python 3.7 标准库服务、应用管理、API 测试。
- 系统 Agent：只读诊断及系统问题报告。
