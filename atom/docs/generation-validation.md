# 真实生成与安装验证 2026 年 10 月 8 日

本次使用透明板保存的 DeepSeek 配置及 deepseek-flash 模型，进行了真实 API 调用，未使用模拟响应或模板替代生成。

复现的问题：原请求成功返回但最终内容为空，应用包解析失败；用户界面只有通用失败提示。DeepSeek 当前默认启用思考模式，因此小应用生成显式关闭思考，启用 JSON 输出并改为流式接收。新增空响应、截断和 HTTP 错误的安全提示，不回显密钥或上游响应体。

界面新增真实阶段、动画、已接收字符数和耗时，不显示虚构百分比。轮询不重建表单；生成完成后顶部显示预览和安装按钮。

真机完整验证：从工作坊输入煮茶计时器需求，约 10.4 秒进入预览，点击确认安装，返回桌面打开应用。验证 3 分钟选择、开始后倒计时变化、暂停后时间不变、重置恢复 3 分钟。1/3/5 分钟按钮及开始/暂停/重置按钮均在 480×272 内容区域内，前端没有脚本错误。

26 项后端测试在开发环境及透明板 Python 3.7 上通过。新回归测试检查 DeepSeek 流式请求、关闭思考和 JSON 输出参数。

本次耗时仅代表这次调用，不承诺每个应用都在相同时间完成。此次验证使用文字输入；语音转写服务仍未配置。
