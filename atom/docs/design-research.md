# ATOM 480×360 小屏设计研究

研究日期：2026-10-08。目标是学习成熟产品如何处理约束，不复制品牌字体、图标、颜色组合或界面。下面将官方原意与 ATOM 推论分开；尺寸建议是待真机验证的项目基线，不是官方规范。

## 来源与可迁移经验

### Playdate

[官方 Designing for Playdate](https://help.play.date/developer/designing-for-playdate/)强调小屏内容的物理可读性、在真实硬件上检查表现，以及只重绘发生变化的内容；模拟器的尺寸与性能不能替代真机。它将主要操作和返回行为保持一致，并建议用视觉反馈补充声音反馈。原设备是 400×240 单色掌机，其字体像素高度定义也不同于 CSS font-size，不能照搬数值。

**ATOM 推论：** 桌面预览必须使用 480×360 的原始尺寸；实机检查中文字形和观看距离。优先局部更新，禁止为静态时钟持续全屏动画。Home 始终返回系统，应用内返回只退一层。计时结束既显示结果也发声。

### teenage engineering OP-1

[官方 synthesizer mode 指南](https://teenage.engineering/guides/op-1/original/synthesizer-mode)说明四个模块与 T1–T4 操作键的固定对应，主引擎画面先出现，再按模块调整。该设计依赖实体按键与旋钮，不能直接搬进触控网页。

**ATOM 推论：** 每个应用首先露出核心内容与主操作，设置放在下一层。少量稳定的位置和语义，比把全部选项挤入一屏更易掌握。色彩可以标记功能，但必须配合文字或形状，不把颜色当唯一含义。

### Apple HIG

[官方 Layout](https://developer.apple.com/design/human-interface-guidelines/layout)与[Typography](https://developer.apple.com/design/human-interface-guidelines/typography)作为布局与文字设计的后续阅读入口。此次网页正文依赖动态加载，工具没有获得完整正文，因此不声称验证了其中的具体尺寸或规则，也不将 Apple 点数直接换算为 ATOM 像素。

**ATOM 独立推论：** 用明确的内容层级、对齐和一致间距组织页面；中文正文建议从 16–18px 开始实测，低于 14px 的文字进入人工复查。优先系统字体与本地资源，不让字体 CDN 成为启动依赖。

## ATOM 第一轮可执行基线

- 固定按 480×360 设计，首页一项核心内容加少量操作；长列表允许滚动，操作按钮不被裁切。
- 一屏通常只有一个最突出的主操作，常见动作使用动词标签；按钮有可见焦点和按下反馈。
- 间距从 8px 网格开始，边缘留约 12–16px；这是初始试验值。
- 正文从 16–18px 起，次要标签尽量不低于 14px。计时、时间等关键数字可放大，避免文字塞入小装饰卡片。
- 基础面、文字、分隔线与一项强调色即可形成层级；渐变并非禁止，但不作为所有面板的默认装饰。
- 不展示随机变动的 CPU、天气、任务进度冒充实测；数据缺失显示不可用，演示数据标记演示。
- 网络失败、未授权、空内容、运行中、完成、失败均有可理解的状态；不要永远显示 loading。
- 所有资源随应用部署，本地交互断网可用。外部服务明确依赖、超时与重试。
- 真机验证：原尺寸截图、鼠标/键盘焦点、完整主流程、断网、长中文、闲置一分钟 CPU、返回后定时器释放。

## 给应用生成模型的提示词模板

> 为 ATOM 制作一个真实可用的桌面小应用：[具体用途]。运行视口 480×360，Chromium 91，原生 HTML/CSS/JavaScript，无构建工具、无 CDN、无远程字体。输出 manifest.json 与 UTF-8 本地文件，入口固定 index.html。先给一项清晰主任务，再给必要的次要操作。使用语义按钮、清楚的中文动词标签、可见焦点与操作反馈；正文从 16–18px 开始，避免小字挤满面板。建立独立视觉方案，不复制品牌，不默认添加渐变、玻璃面板和虚构指标。实现完整状态与真实逻辑；外部数据不可用时诚实提示，演示数据必须标记。说明数据来源、存储行为、网络依赖和计时器释放方式。完成后在 480×360 原尺寸检查裁切、长中文、主要操作以及断网行为。

再根据用途补充：时钟突出时间；计时器突出剩余时间与开始/暂停；信息面板突出数据来源和更新时间。不要用同一种卡片模板套所有应用。

## 静态质量检查工具

`python3 atom/tools/check_app.py atom/examples/breathe.json`（JSON bundle）或 `python3 atom/tools/check_app.py <应用目录>`：结构错误退出 1，警告不阻止部署。检查 manifest、路径、符号链接、入口、UTF-8 和大小；提示 viewport、交互标签、外部依赖、小字号、渐变声明数量以及可能的演示数据。

这是源代码启发式检查，不渲染页面，不判断布局是否美观，不识别所谓“AI 味”，不证明数据真假。canvas 控件、变量字号、动态 DOM 和合法随机游戏可能产生漏报或误报。必须结合截图和真机流程复查。

JSON bundle 格式为 `{manifest:{...},files:{"index.html":"..."}}`；工具先验证所有文件路径，再写入独立临时目录进行检查，结束后清理，不修改原 bundle。
