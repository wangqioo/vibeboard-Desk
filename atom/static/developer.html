连接与部署

在开发者页面查看设备局域网 IP。电脑和 ATOM 连接同一个局域网后，在电脑终端运行：

ssh linaro@设备IP

SSH 使用设备现有服务和账户，请输入你的设备密码或配置公钥。默认端口是 22。开发模式不会自动配置 SSH，也不会自动连接电脑 Agent。

制作应用包

应用使用 HTML、CSS、JavaScript，入口固定 index.html。保存以下结构为 UTF-8 JSON 文件：

{
  "manifest": {
    "id": "hello",
    "name": "你好",
    "description": "第一个桌面应用",
    "entry": "index.html"
  },
  "files": {
    "index.html": "<!doctype html><html lang='zh-CN'><meta charset='utf-8'><body>你好，ATOM！</body></html>"
  }
}

在设备的“应用管理”中选择“安装应用”，打开 JSON 文件。更新时选择“导入更新”，保持相同 id。导入包最多 2 MiB，最多 100 个文本文件。

应用隔离运行，无法直接操作主页或调用设备管理 API。硬件权限与电脑 Agent 接口需要后续显式接入。
